# MeguvizCAC v1.1.0 — `MeguvizOmni-Guard` 正交双轴与可插拔多能力演进路线图

> **定位**：在不牺牲纯文本 AI 检测 SOTA 精度（`<= 2.20 MB` Bundle v6 / `~1 ms` 端侧级联 / 绝对 `Zero-PII`）的前提下，将 MeguvizCAC 从单一的“AI 评论二分类检测器”演进为 **“正交双轴（AI 生成源 × 商业推广/软广/引流意图）+ 可插拔多治理能力底座”**。

## 1. 核心动机与语料实证（为什么单轴 `p_ai` 必然碰壁）

对 `v04-merged-1m4-r3.jsonl.gz` 全部 `1,372,143` 条训练样本的实证扫描揭示了单轴二分类的根本结构冲突：

| 非有机商业/模板模式 | 训练集命中条数 | 现行单轴分布 (`hu<=30 / mid / ai>=70`) | 单轴结构冲突诊断 |
| :--- | ---: | :--- | :--- |
| 带货券商 (`coupon_ad`) | `1,930` | `86.3%` / `9.7%` / `4.0%` | 强模板化人类广告被迫挤入有机人类流形，破坏决策边界 |
| 自推广引流 (`self_promo`) | `848` | `60.3%` / `8.7%` / `31.0%` | 直接拦腰撕裂，导致模型在引流/英文自我推广样本上严重震荡 |
| 软广托儿 (`soft_shill`) | `127` | `26.0%` / `7.9%` / `66.1%` | 劝购套话与 AI 腔调高度混叠，单轴无法区分“真人托儿”与“AI 软广” |
| 课代表/AI 摘要免责 (`kedaibiao`) | `14,771` | `7.0%` / `1.3%` / `91.7%` | 易触发 `"AI生成"` 关键词快捷方式，导致无害免责声明冲顶压垮 `R@P95` |

**第一性原理结论**：**“是否由 AI 生成（Origin）”** 与 **“是否具有商业推广/引流/水军意图（Intent）”** 是两条**数学正交**的轴。将其解耦不仅赋予模型精准识别真人硬广/自推广/软广托儿的新能力，还能够通过给商业推广样本提供独立的能量归属谷，**反向清除纯 AI 检测的边界假阳**。

## 2. 顶层语义体系：正交双轴四象限（Zero-PII Compliant）

### 2.1 主轴 X — 生成来源轴 (`Origin Axis`, 100% 向下兼容纯 AI 基准)
- **`p_ai ∈ [0, 1]`**：严格度量文本是否由 LLM / 自动化代理生成，绝不将纯真人广告强行标为 AI。
- **6-Way Origin Attribution**（升级自 `ATTRIBUTION_5WAY`）：
  1. `Human-Organic`（原生有机真人互动）
  2. **`Human-Commercial-Promo`（新增：真人硬广 / 券商带货 / 自推广引流 / 真人托儿）**
  3. `Human-Assisted`（人工润色 / AI 摘要课代表免责）
  4. `Script-Plugin-Bot`（规则脚本 / 模板回复机）
  5. `Autonomous-Persona-Agent`（自主拟人 AI 账号）
  6. `Coordinated-Latent-Cluster`（协同潜伏集群）

### 2.2 主轴 Y — 商业推广与功利意图轴 (`Promotional Intent Axis`)
- **`p_promo ∈ [0, 1]`**：总推广/营销/引流意图强度（独立二分类头，不受 `p_ai` 互斥约束）。
- **4 个正交多标签子头（`Sigmoid`，允许复合命中）**：
  - `Y1: coupon_commerce` — 券商带货、满减凑单、返佣蓝链、二手引流（如 `【夯】【券80元】`）
  - `Y2: self_promo_funnel` — 自推引流、求关注/互关、主页领资料、加微/进群、`check my channel`
  - `Y3: soft_shill` — 软广托儿、假路人“亲测闭眼入/回购三次”、无关键词劝购、拉踩竞品水军
  - `Y4: tool_boilerplate` — 课代表摘要、AI 辅助免责声明、高频复制粘贴梗（用于区分无害工具与恶意营销）

### 2.3 四象限治理策略矩阵（策略权交给前端/用户，模型只提供精准坐标）

| 象限 | `p_ai` | `p_promo` | 典型评论画像 | 建议治理动作 |
| :--- | :---: | :---: | :--- | :--- |
| **Q1 · 纯 AI 养号/水评** | 高 | 低 | 伪口语金句体 AI、拟人“本鱼/本鲸”互动 | 标记 `AI 评论` |
| **Q2 · AIGC 营销/矩阵水军** | 高 | 高 | 批量生成软广、自动化带货回复、AI 伪装测评托儿 | 标记 `AI 营销水军`（最高优先级拦截） |
| **Q3 · 真人广告/自推/托儿** | 低 | 高 | 真人券商凑单表、求关注主页领资料、真人硬/软广 | 标记 `真人推广/广告`（精准折叠，不误冤枉成 AI） |
| **Q4 · 有机真人讨论** | 低 | 低 | 真心安利（带优缺点）、开源仓库指路 (`github/arxiv`)、影评评分卡、正常比价吐槽 | 放行 |

## 3. 架构演进：零痛寄生 `v1.0.0` 骨架（`< +25 KB`，`< +0.01 ms`）

基于 `v1.0.0-ApexLoop` (`TunnelSymplect × DynaCore-MoLE × Zero-Recompute 3-Stage Cascade`) 进行轻量增量升级，总包仍稳守 **`<= 2.20 MB`**、WebGPU SRAM **`<= 32 KB`**：

1. **内环解析 `EBT` 升级为 `6-Way` 能量地形（`+192 字节` FP16）**：
   - `InLoopAnalyticEBTV10` 输出由 `5 -> 6`，新增 `Human-Commercial-Promo` 独立低能谷；
   - `ebt_ai_margin = min(E_organic, E_promo) - min(E_bot, E_agent, E_cluster)`；
   - `ebt_promo_margin = E_organic - E_promo`；
   - **反向增益**：真人推广样本被直接吸入 `E_promo` 低能谷，不再在 `Organic` 与 `AI` 之间震荡，同步抬升纯 AI `R@P95`。
2. **`256-d` 正交子空间解耦 + 负迁移防火墙（`0 KB` 运行时开销）**：
   - 将 `coda_proj` 输出的 `emb (256-d)` 划分为：`[0:128]` 共享语义与语体核、`[128:192]` AI 生成源专有区、`[192:256]` 商业推广与未来治理能力专有区；
   - `ai_head` 读 `[0:192]`，`promo_head` + `promo_sub4_head` 读 `[0:128] ∪ [192:256]`；
   - 训练期施加轻量头权重正交解耦正则 `λ_orth * |cos(W_ai[:, :128], W_promo[:, :128])|²` 与专有区梯度隔离，确保新增任务对纯 AI 检测零负迁移。
3. **`E3 DynaCore-MoLE` 热插拔专家槽（`8 -> 10` 专家，`+4.6 KB` FP16）**：
   - 保持 `1 Shared` 核心不变，在 `8` 个 `v1.0.0` 专家核旁热插拔新增 `E9`（券商/比价/外链引流核）与 `E10`（软广劝购/CTA 话术核），共 `10 × 24 × 24 × 2 B = 11.5 KB` 增量可控；
   - 未来扩展反诈、情绪引战、刷屏复读等新治理能力时，只需按同样范式挂载 `+2.3 KB` FP16 专家核 + `~4 KB` 任务头，底层主干永远只跑 **1 次 `~1 ms` 前向推理**。
4. **Zero-PII 纯文本商业线索扩展（`Style 40-d -> 48-d`，`+2 KB`）**：
   - 严守 Zero-PII 铁律（绝不引入账号等级、UID、昵称、注册时间），仅新增 `8` 维纯文本特征：
     - 价格/折扣/满减数字模式密度、多商品并列密度、CTA 行动召唤动词（关注/私信/领/戳/冲/加微）、社交引流词（主页/简介/扣群/VX）；
     - **外链语义分流**：白名单开源/学术域名（`github.com / arxiv.org / huggingface.co / docs.*`）与电商/短链/导流域名分离编码，防止误杀正常技术指路；
     - 课代表/免责声明锚点标志、极端赞美/劝购修饰密度、自我推广英文模式。
5. **`TinyScope-CBM (128 概念)` 显式可解释槽**：
   - 预留 16 个半监督概念槽绑定到 `{ai_cadence, persona_leak, coupon_list, cta_funnel, soft_shill_praise, organic_critique, open_source_ref, disclaimer_template, ...}`，实现零额外算力白盒归因输出。

## 6. 长文本判断能力进化（实证诊断 × `ChronoStream × DynaSeam-MIL`）

### 6.1 `v0.5–v1.0` 长文本四大硬伤（本地实证定位）

对 `v04-merged-1m4-r3` 全部 `1,372,143` 条训练语料及 `v0.9.0-R1` 在 `validation / test` 上的分长度桶扫描暴露了四大结构瓶颈：

1. **长尾训练极度饥饿与长度先验偏置**：训练集中 `> 256` 字仅占 **`0.54%`**，`> 384` 字中 **`90%+` 是人类**（`> 1024` 字仅 `2` 条 AI）。导致 `v0.9-R1` 在 `321–512` 字桶上 `test PR` 从 `0.9858` 跌至 **`0.5903`**、`val FPR@0.5` 从 `0.4%` 暴涨 **`25×`** 至 **`10.0%`**、`> 512` 字桶 `mean_p_hu` 抬升至 `0.193`（短评仅 `0.045`），而长 AI 召回均值从 `0.946` 跌至 `0.616`。
2. **`v05_features.py` 隐蔽的 `512 -> 191` 特征断崖 Bug**：`extract_style_features_32d()` 传入 `max_len=512` 却在内部误用硬编码 `HEAD_CHARS_V05(140) + TAIL_CHARS_V05(50) = 191`，导致文本从 `510` 字增加 `9` 字到 `519` 字时特征瞬间跳变 **`0.3148`**；此外原特征在清洗阶段提前吞掉换行 `\n`（丧失段落结构）、用绝对计数 `count / 4`（长文全部饱和为 `1.0`）、原始 `TTR` 随长度单调衰减，且表情正则漏掉 B 站长名官方表情（如 `[TES·2026薪火耀新程_冲鸭]`）引发长文误杀。
3. **生产端 `head72 + tail28` 截断导致“夹心长文”完全致盲**：`MeguvizV10CascadeEngine` 对超过 `256` token 的长文直接切掉中段，在真实拼装的 `Human + Mid-AI + Human` 夹心长文上检出率仅 **`10.0%`**，微型 `1`-Chunk AI 埋伏检出率为 **`0.0%`**！
4. **朴素流式 `max(chunks)` 引发引用误杀爆炸与长文 FPR 膨胀**：旧 PyTorch `forward_streaming_long()` 直接取 `max(chunk_probs)`，导致真人长评仅仅**引用吐槽**一段 AI 原文（`「…AI原文…」`）时误杀率高达 **`66.7%`**，且随分块数 `M` 呈 $1 - (1-\text{FPR})^M$ 指数膨胀；而朴素 `mean(chunks)` 又会将夹心与尾部注入彻底稀释（检出仅 `6.7%–18.3%`）。

### 6.2 `v1.1.0` 四位一体长文本演进方案（短文 `0` 额外延迟，长文 `O(1)` 恒定显存）

1. **长度无关 `56-d` 宏观语体前端（[v11_features.py](../meguviz_cac/v11_features.py)）**：
   - `max_chars = 8192` 全文平滑扫描，彻底消灭 `512 -> 191` 断崖（`508 -> 518` 字最大特征跳变由 `0.3148` 降至 **`0.017`**，`Zero-PII diff === 0.000000`）；
   - 以每百字平滑密度率与 **`MATTR-64`（滑动窗口词丰富度均值 + 标准差）** 替换饱和计数与受长度混淆的 `TTR`；
   - 在折叠空白前完整保留 `\n+` 段落结构，新增 `8-d` 长文宏观指纹：**段落数、段落长度变异系数 `para_len_cv`（捕捉 AI 均匀段落节律塌缩）、句长突发性 `sent_cv`、`MATTR_std`、首尾词汇漂移 `ht_drift`、`4-gram` 复读刷屏率 `rep4_ratio`（秒杀复读梗/滚键盘长文误杀）、Markdown 框架密度、引用占比**；
   - 升级 B 站官方长表情正则并分离“开源/学术白名单外链”与“电商/导流外链”。
2. **句段边界感知分块 + 引用归因追踪（`plan_long_chunks_v11`）**：
   - 在 `±45` 字窗口内自动吸附至 `\n+` 或 `。！？!?；;` 边界，避免腰斩 AI 反差排比句；
   - 精确追踪每块 `quote_frac`（引号/代码块覆盖占比）与 `has_quote_intro`（如 `原文如下/AI生成的/引用一下`），并将块级局部语体与文档全局 `56-d` 宏观指纹分离输入。
3. **恒等残差锚定 `DynaSeam-MIL` 静态 ONNX 流式聚合器（[v11_longstream.py](../meguviz_cac/v11_longstream.py)，仅 `+33.7 KB` FP16，`0.194 ms` 1T-CPU）**：
   - **纯 WebGPU / ONNX Opset-17 原生设计（`0` 个 RNN/GRU 算子）**：相邻分块变化点缝隙雷达（`Seam Radar`，融合特征突变、余弦跳变、`Δlogit_ai`、`Δlogit_promo`、`Δquote`）+ 1 层 `32-d` 全局分块自注意力（`M=1..24`）+ 局部 `k=3` 深度卷积；
   - **引用门控注意力 MIL（`Quote-Gated Attention MIL`）**：在 `AI Authorship` 轴显式扣除引号/归因块权重，而在 `Promo/Soft-Shill` 轴采用**非对称局部峰值敏感 MIL**（精准抓出“800 字干货教程 + 末尾 150 字软广/引流”的隐藏尾广）；
   - **单块恒等残差门控（`multi_gate = clamp(M-1, 0, 1)`）**：数学严格保证 `M == 1` 短/单块评论 `max_diff === 0.000000` **绝对零退化**；`M >= 2` 时以校准后的去引用块基线为锚点叠加 `DynaSeam` 残差修正，并同步输出 **`p_ai_doc`、`p_hybrid_doc`（区分纯 AI 与 `Human-Assisted` 人机混合）、`p_promo_doc`、`ai_coverage_ratio` 及分块定位热图**。
4. **训练期 `ChronoStream` 跨块状态延续 + `LongMix` 零成本长文合成课程**：
   - Stage 1 中引入 `15%` 多块流式训练批次（`2–3` 块 TBPTT），端到端训练 `BLTMatryoshkaPreludeL0` 的 `fwd_state`（`16 KB`）与跨块 `z_H` 慢判决槽延续（`3 KB`）+ `Top-32 L0-Haar` 缝隙草图（`8 KB`），恒定 **`27 KB` SRAM** 支持 `4,096+` token；
   - 引入 **`Length-IPW` 长度反倾向加权 + `LongMix` 在线八原型合成课程**（混入真实单作者 `> 220` 字长评与纯长人、复读/表情硬负、纯长 AI、双段夹心、`1`-Chunk 微型埋伏、尾部注入、裸引号引用 AI、零过渡词隐藏尾广），彻底根除“长文=人类”的先验捷径。
